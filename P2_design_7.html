Authors: Lea, Dana, Elena and Marie

Date: 9 October 2026

Client

Our client is Cathrine Cat. She is the owner of Purr & Pour, a cat cafe dedicated to animal rights and mental health.

Purpose, goals and audience

Our purpose is to create a website that promotes the cat cafe and its values, while providing information about the cats, menu, and policies.

The goals are to increase awareness of the rescued cats, where they can find a loving home, or just feel comfortable and safe. Furthermore, we aim to educate visitors about the importance of adopting cats and supporting animal welfare.

Main audience: Cat lovers, individuals seeking stress relief, and those interested in animal welfare, local sourcing and those who seek a new pet.

Fonts

We use the font Nunito on the whole website, with sans-serif as a backup.

  • Body text: Nunito, 1rem, regular
  • Main heading (h1): Nunito, 2rem, medium 500
  • Section headings (h2): Nunito, 1.5rem, medium 500
  • Navigation links: Nunito, 1.2rem, regular (active page in semibold, 600)

Our client Cathrine Cat wished for rounded features. We felt that Nunito's rounded letterforms would complement this aesthetic.

Our client Cathrine Cat wanted a clean look with soft colors that represent the planet. We therefore chose a calm palette of soft greens on a warm off-white background, with green used as an accent for headings, links and borders. To make the text easy to read, we use dark grey for the body text and a darker green for links, as the original soft green did not have enough contrast against the background.

Different JavaScript-functions

We are having 4 different JavaScripts, nav.js which is the navigation bar, footer.js that shows our names in the bottom of every html file. A hoover.js that enlarges the “adopt me” button. The last JavaScript file we will have is a validation for the booking.html, which checks if you have filled in the two buttons.

Four distinct responsive components

  1. We have the navbar, when the screen-size is under 700px the navbar turns into a burger-menu.
  2. We are also planning on using grid to scale the cat-cards.For example: we have 3 on computer-screens, 2 on ipads and 1on phones.
  3. The third component is that the pictures will change sizes to adjust to the screen size, this will also make the useability improve.
  4. The last component we are planning on is that the textboxes will change according to the layout. We can use Flexbox and flex-wrap to make this work.

How we are using CSS for the layout now

We use CCS grid for the header. The .meny class is a grid with three columns (grid-template-columns) and the .nav-grid class uses grid-template-columns: auto auto to lay out the navigation links.
The .info class uses Flexbox, display:flex with gap:2rem, so the author, client and date on the P1 HTML document lines up, side by side.
We also use width, padding, margin and border to change the layout of content boxes. The textbox1 and textbox2-classes both use width:90%, max-width 1500px and padding 20px so they dont get to wide for the window. We have also use border and border-radius to give a softer look. All layout is now written in one stylesheet, style.css.

Accessibility measures

ARIA- Accessible Rich Internet Applications, its a set off attributes you add to HTML to share extra information to the screen readers that necessarily isn't clear from just the code itself.
In the nav.js we have used aria-label that gives an element a name that the screen reader reads out.
aria-expanded tells us if something is open or closed. button aria-expanded="false/true"
aria-current = “page” marks the link to the page the user is on, a href="booking.html" aria-current="page">Booking here the screen reader will say “Booking, current page.”

Alt text on images – every has an alt that describes the image, for example: alt= “Toffe, a Scottish fold cat”

Labels- labels are what points to the id of the input. For example in the booking.html, the “” will make the screen reader read “Email”

Visible focus for keyboard users- we are using CSS to make a outline when you navigate with Tab through the website.

Contrast between text and background – we have made the font color a color that wil pass the WCAG (Web Content Accessibility Guidelines) requirements.
